## 1. 为什么是蝴蝶效应

| 判断 | 说明 |
|---|---|
| 叙事最贴定位 | 「一点扰动 → 工作被改写」直接对应「一点接入，工作换轨」，首屏一张图就能讲完定位 |
| 四个词都有落点 | 基元＝中心一点；律动＝等距外扩；组织＝波纹擦过工作面；进化＝外圈细线回流。不用另画机制图 |
| 能撑起全站 | 同一个涟漪场可以变成图标、分隔、过渡和结尾，换个视角（透视 / 俯视）就是新版式，不必再造图形 |
| 风险可控 | 最大风险是画成写实蝴蝶或水纹贴图，本稿一律用几何线、点阵和程序绘制，不用照片和插画 |

## 2. 首屏

[首屏 · 桌面 1440](/brand-collection/assets/tokenrhythm/hero-desktop.webp)

- **构图**：左文右图。涟漪中心在画面 69% / 56% 处，场的视觉权重过半；左侧 30% 用渐变压暗，给标题留出安静的底。
- **主物**：中心一点冷白高光 + 4 圈等距几何环（透视成椭圆）。环每 2 秒从中心生成一圈，匀速外扩并在外圈淡出；底下一层稀疏点阵只在波前经过时被轻轻抬起、变亮。
- **组织**：3 块抽象工作台浮在场上方。波纹擦过时边框变亮，每隔几圈面板里的条块重排、色块点亮，表示「工作被改写」。界面块没有可读文字。
- **进化**：一条青绿虚线从外圈回流到中心，虚线持续向中心流动，面积很小。
- **交互**：鼠标移动时视角轻微偏转；点击画面或「发出一次扰动」按钮，会从中心发出一圈更快更亮的波，经过的工作台立刻重排。
- **静帧**：系统开启「减弱动态效果」时只渲染一帧。固定的 4 圈参考环保证静帧也读得出「中心 → 外扩 → 改变」。

## 3. 全站图形语法

首屏的涟漪场拆成四个小图形，内页只用这四个，不再引入新图形。

[方法区：四个图形](/brand-collection/assets/tokenrhythm/grammar.webp)

| 图形 | 画法 | 品牌词 | 业务挂钩 |
|---|---|---|---|
| 一点 | 白芯 + 冷青辉光 | 基元 | 模型接入 |
| 等距环 | 3 圈等距细环，循环外扩 | 律动 | 智能组织 |
| 环擦面 | 环的一段压过一块抽象面板 | 组织 | 路由与工作流 |
| 回流线 | 外圈到中心的点状虚线 | 进化 | 经验回写 / 后训练 |

用到它们的地方：

- **工作流区**：一次调用沿横向轨道走过「接入 → 组织 → 交付 → 回写」，每到一个节点发出一圈小波纹（环的侧视）。
- **工作台示意**：左右两块抽象工作台，滚动到这里时右侧被一圈波纹扫过，条块重排、色块点亮。

[工作流区与工作台示意](/brand-collection/assets/tokenrhythm/flow.webp)

- **结尾区**：同一个场改为俯视，变成正圆同心环和回流螺线，配「让智能协同进化」。

[结尾区：俯视的涟漪场](/brand-collection/assets/tokenrhythm/closing.webp)

## 4. 色彩与字体

| 角色 | 值 | 用法 |
|---|---|---|
| 画布 | `#05070C` → `#0A1220` | 页面底色；首屏中心有一团 `#0A1220` 的暗光 |
| 卡片 | `#0E1624` / 悬停 `#152033` | 受众卡、工作台 |
| 正文 / 次级 / 弱 | `#E8EEF7` / `#9AA8BC` / `#5F6C80` | 三级文字 |
| 主高光 | `#A8E0FF`、`#7EC8FF` | 中心点、环、按钮光晕 |
| 辅高光 | `#6EE7D8` | **只用于回流线和注释**，表示「进化」 |
| 线 | `rgba(168,224,255,.09)` | 分隔线、卡片边 |

- 不用橙、黄、紫雾和彩虹渐变；`#5B8CFF` 预留，本稿没用到。
- 字体：Inter + 系统中文（苹方 / 微软雅黑）；JetBrains Mono 用于眉题、编号和英文口号。标题 600 字重、略收字距；正文 16–17px，行高 1.7–1.8。
- 主按钮是近白实心胶囊，次按钮是细描边；悬停只加一圈冷青光晕。

## 5. 动效参数

| 项 | 值 |
|---|---|
| 生成周期 | 每 2 秒一圈，环距 1 个单位，速度 0.5 单位/秒 |
| 可见环数 | 约 4 圈；0–0.5 淡入，外圈最后 1.6 个单位淡出 |
| 点击扰动 | 单圈，速度 ×3，亮度更高，经过的工作台立即重排 |
| 视角 | 俯仰约 29°，鼠标带动偏航 ±0.11 rad、俯仰 ±0.025 rad，缓动跟随 |
| 工作台 | 每被波纹擦过 3 次重排一次，重排过渡 0.9 秒 |
| 回流线 | 虚线 2/7，持续向中心流动 |
| 性能 | Canvas 2D；滚出视口即暂停；像素比上限 2 |
| 无障碍 | 「减弱动态效果」下只画静帧、隐藏扰动按钮；画布 `aria-hidden`，文字信息不依赖动画 |

## 6. 禁区自查

对照概念包 §1 首屏总禁区、§3-1 不做清单和 §5 全局负面：

| 禁区 | 本稿 |
|---|---|
| 写实蝴蝶 / 翅脉 / 标本 | 无。只有几何环和点阵 |
| DJ 声波墙 / 粒子爆炸 | 无。点阵只在波前处轻微抬起，不飞散 |
| 路由矩阵 / 机房 / 模型 logo 墙作首屏 | 无。工作台是抽象块，不画路由图 |
| 橙、黄促销、紫雾、彩虹 | 无。只有冷青、冷白，加一处极少量的青绿 |
| 指挥家 / 乐队主视觉 | 无 |
| 编造数字、贬损竞品、「改变人生」 | 无。文案落在工作流、交付、协同 |
| 多方向混搭首屏 | 无。光谱、星群、潮汐等方向的元素都没有用 |

## 7. 还需要确认的事

1. **标志**：概念稿里的「点 + 两圈」只是占位，不是标志提案。正式字标 / 图形标需要另外出稿，再回头统一。
2. **产品事实**：「一个入口调用」「经验回写」等说法沿用概念包的业务挂钩写法。接入方式、支持的模型、回写的具体机制需要产品方确认后再写细。
3. **两个域名的分工**：tokenrhythm.studio 与 opensquilla.ai 分别承担什么（品牌站 / 产品站 / 开源项目），决定页脚和导航怎么写。
4. **英文版**：现在只有中文正文和英文口号。
5. **生图主视觉**：如果需要静态海报或社媒图，可用概念包 §3-1 的提示词 A / B 生图，构图按本页第 2 节对齐，也可以直接用概念稿截图。
