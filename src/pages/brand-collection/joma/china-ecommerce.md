## 四、观察：中国电商 vs 国际站差异

| 维度 | 中国电商（本次公开可见） | 国际站（既有调研对照） |
|------|--------------------------|------------------------|
| **译名** | 文案混用「荷马 / 骄马 / 霍马」；店名以拉丁「JOMA/joma」为主，专卖店偶嵌「荷马」 | 统一 Joma / JOMA，无中文译名压力 |
| **Logo** | 主图普遍拉丁小写词标 + 鞋侧「J」；**未见正式中文图形标** | 页头鹰形+词标 SVG；产品「J」单标；色值官网 CSS 多见 `#0026FF` |
| **色彩** | 促销红条（京东开学季）强烈；产品仍用品牌蓝/高对比霓虹色；「蒂芙尼蓝」等**本地流行色名**写入主图 | 深蓝识别 + 酸柠辅色；相对少平台红促销套版 |
| **卖点话术** | 中英混排科技缩写中文化（膜压/一体成型/真皮鞋面）；场地词「TF碎钉」「MG短钉」「半袋」；价格阶梯满减 | 英语品类大写（FOOTBALL/RUNNING）、技术参数海报；少「满减」视觉 |
| **构图** | 1:1 主图；暗底能量光效或同色铺底；多色 SKU 一图展示；底部强制促销条 | 宽幅轮播、球星/赛事故事、目录封面；较少平台吉祥物角标 |
| **Slogan** | 「创立于1965年 西班牙运动品牌」「SINCE 1965」「优雅永不过时」「ALL FOR SPORT」 | 国际站更多品类/系列叙事；heritage 亦强调 1965，但呈现更偏官网编辑风格 |
| **品类重心** | 公开货盘强烈偏**足球鞋（TF/MG/IN）+ 训练紧身衣**，价格带常百元–四百 | 官网同时推 Teamwear、Running、Trail、Padel 等全线 |
| **抓取局限** | 旗舰店首页/店招/详情长图被登录与 SPA 挡住；只能靠导购站 alicdn/zdmimg 转载 | 官网静态资源相对易 curl |

## 五、缺口与下一步建议（不编造部分）

1. **店招/店铺首页**：需登录态浏览器或官方提供装修导出，本次公开网页**未能替代登录截图**。  
2. **详情长图 / 包装**：建议授权后从天猫/京东商家后台或买样开箱补齐。  
3. **中文标准字**：品牌升级需先决策「荷马 vs 骄马 vs 仅用 JOMA」，目前公开层无锁死字形。  
4. **双店并存**（天猫官方旗舰 + 运动旗舰；京东官方旗舰 + 自营旗舰）→ 视觉规范需统一，否则消费者识别分裂。
